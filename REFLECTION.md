# Reflection

## 1. What did you ask Copilot to help you build? How did you break down the problem?

I asked GitHub Copilot to help me build a simple social media feed called ConnectHub using HTML, CSS, and JavaScript. I broke the project down into smaller parts instead of asking Copilot to build everything at once. I started with the basic structure, then worked on posting content and adding a Like button.

## 2. How did your approach to asking questions change as you worked?

At first, I used a broader prompt to have Copilot create the basic structure of the application. As I worked, I started using more specific prompts that focused on one feature at a time. This helped me understand what Copilot was changing and made it easier to test each feature.

## 3. What parts of development with GitHub Copilot surprised you?

I was surprised by how quickly Copilot could create working code and test the application. I also noticed that Copilot could recognize when something was already implemented. For example, when I asked it to add the ability to submit a post, it explained that the feature was already working and did not make unnecessary changes.

## 4. What did you learn about the technology you used that you didn’t know before?

I learned more about how HTML, CSS, and JavaScript work together to create an interactive website. I also learned that JavaScript can update the page without refreshing it, such as adding a new post or changing a Like button when it is clicked.

## 5. What would you do differently if building again?

If I built the application again, I would plan out more of the features before starting and use even more specific prompts with Copilot. I would also spend more time improving the design and adding additional features after making sure the basic functionality worked.
